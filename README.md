# Villa JIJI — სატესტო საიტი

ბაკურიანის ვილა JIJI-ის საიტის დემო: საიტი, სცენარიანი ჩატბოტი და მფლობელის პანელი.

## გვერდები

- `index.html` — საიტი. ცოცხალი თოვლი, სეზონები, ბუხრის ოთახი, ნომრები და ჯავშნის მოთხოვნა.
- `admin.html` — მფლობელის პანელი (სადემონსტრაციო PIN: `1234`):
  - **მოთხოვნები** — დადასტურება ან უარყოფა. დადასტურებისას თავისუფალი ნომერი ავტომატურად ინიშნება.
  - **კალენდარი** — 8 ნომერი × 14 დღე. ცარიელ უჯრაზე დაჭერით ჯავშანი ხელით ემატება.
  - **ფასები** — ფასები ნომრის ტიპისა და სეზონის მიხედვით. ჩატბოტი და საიტი ფასს აქედან ითვლიან.
- ჩატბოტი (`js/chat.js`) — ღილაკებიანი სცენარი AI-ის გარეშე: თავისუფალი ნომრები და ფასი, მისამართი, ხშირი კითხვები, მფლობელთან დაკავშირება. თუ თარიღი დაკავებულია, უახლოეს თავისუფალ თარიღს სთავაზობს.

## როგორ მუშაობს

ჯავშნის გადახდა არ ხდება: სტუმარი აგზავნის მოთხოვნას, მფლობელი კი პანელში ადასტურებს. მოთხოვნა ნომერს არ იკავებს, ნომერი მხოლოდ დადასტურების შემდეგ იბლოკება.

**დემოს შეზღუდვა:** მონაცემები ბრაუზერში (`localStorage`) ინახება. სტუმრის და მფლობელის მხარე ერთსა და იმავე მოწყობილობაზე უნდა გახსნათ. ფასები, ნომრების განაწილება და ჯავშნები სანიმუშოა.

## შემდეგი ნაბიჯები

1. `js/store.js` შეიცვლება Supabase-ის ბაზით: მოთხოვნები სხვადასხვა ტელეფონს შორის იმუშავებს, პანელს ნამდვილი შესვლა ექნება.
2. იგივე სცენარი მიუერთდება Instagram-ს და Facebook Messenger-ს.
3. Booking.com-თან და Airbnb-თან კალენდრის სინქრონიზაცია (iCal).
4. ინგლისური და რუსული თარგმანი.

## ვიდეოები

დემოში ახალი წლის ვიდეო (`video/new-year.mp4`, დაახლ. 11 MB) საიტთან ერთადაა და მხოლოდ "ვიდეოს ნახვა"-ზე დაჭერისას იტვირთება. ნამდვილ საიტზე ვიდეოები YouTube-ზე აიტვირთება: `index.html`-ში `<video>`-ის ნაცვლად ჩაისმება `https://www.youtube-nocookie.com/embed/VIDEO_ID?autoplay=1` iframe, ხოლო `video/` საქაღალდე წაიშლება.

## სეზონები (ზამთარი / ზაფხული)

- სტუმარს მენიუში აქვს გადამრთველი ზამთარი / ზაფხული. მისი არჩევანი ბრაუზერში იმახსოვრება.
- ადმინ პანელში (ფასები და სეზონი) ადმინისტრაცია ირჩევს, რომელი სეზონით გაიხსნება საიტი: ავტომატურად თარიღებით (ნაგულისხმევად ზამთარი 15 ნოემბერი – 31 მარტი), ან ყოველთვის ზამთარი / ზაფხული.
- ფოტოს ან ტექსტის სეზონური ვერსია: ელემენტს ემატება `data-w` და `data-s`. სურათზე ფორმატია `"ფაილი|აღწერა"`, ტექსტზე უბრალოდ ტექსტი. სექცია მხოლოდ ზამთარში: კლასი `only-w`, მხოლოდ ზაფხულში: `only-s`.
- ზამთრის ფოტოები `img/winter/`-შია (ახალი წლის ვიდეოდან ამოჭრილი კადრები).
